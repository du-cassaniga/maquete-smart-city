Internet das Coisas aplicada à cidade

Uma cidade que percebe
o que acontece nela.

Esta maquete simula três serviços de uma cidade inteligente: a iluminação pública, uma vaga de estacionamento e uma estação de clima. Sensores medem o ambiente, um Arduino toma decisões simples na hora (como acender o poste quando escurece) e os dados chegam a este site, onde são analisados e mostrados em tempo real.

LDR · pino A0

Iluminação pública

Um sensor de luz mede a claridade. Quando a leitura cai abaixo de 50, o Arduino acende o poste sozinho, sem ninguém apertar botão.

Sensor de presença · pino 3

Estacionamento

O sensor detecta se há um carro na vaga. O motorista poderia consultar de longe se ela está livre antes de sair de casa.

DHT22 · pino 2

Clima

Temperatura e umidade do ar, úteis para alertas de calor, frio ou ar seco para a população.

Como os dados chegam aqui

  1. 01

    Sensores

    LDR, sensor de presença e DHT22 fazem as medições na maquete.

  2. 02

    Arduino Uno

    Lê os sensores, liga o poste se estiver escuro e, a cada 2 segundos, envia uma linha em JSON pelo cabo USB.

  3. 03

    Servidor Python

    Lê a porta serial com pyserial, converte o JSON, guarda o histórico e calcula médias e estatísticas. A API é feita com FastAPI.

  4. 04

    Este site

    Pede os dados à API a cada segundo e atualiza os valores abaixo.
